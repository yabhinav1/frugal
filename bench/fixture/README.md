# shopkit

Small e-commerce toolkit with no dependencies.

- `src/pricing.js` discounts, tax, coupons, price formatting
- `src/cart.js` shopping cart built on pricing
- `src/inventory.js` stock levels and reservations
- `src/orders.js` order creation and status transitions
- `src/store.js` in-memory collection with filter, sort, paginate
- `src/http.js` JSON API handler for `node:http`
- `src/csv.js` CSV import and export
- `src/dates.js` date helpers for delivery estimates
- `src/users.js` user input validation
- `src/utils.js` general helpers

Run the tests with `npm test`.
